# PMI 点播学习助手

在 ProjectManagement.com 筛选点播研讨会，按当前页 PDU 优先选课，并在你观看期间管理播放、评分与切课。Chrome 扩展可直接使用当前浏览器的 PMI 登录会话。

## 本地自动确认版

本分支需单独加载。克隆仓库后切换到 `local-auto-confirm`，在 `chrome://extensions` 选择「加载未打包的扩展程序」，加载该检出目录中的 `chrome-extension`。使用前停用普通版，避免两个扩展接管同一课程。

Chrome 会为 `debugger` 权限提示可访问页面调试器和读写所有网站的数据。本分支只在正在接管的 PMI 课程进入评分阶段时连接课程标签页，只自动确认同一门课的 `Thanks for rating!` 原生提示。确认后或连接超过 90 秒时断开调试。课程只有在网站页面显示已保存 5 星后才切换。调试连接不可用时，可手动确认 Chrome 弹窗。

普通版由 `main` 和常规版本标签维护。此分支使用带 `-local` 的专用标签。Chrome Manifest 版本仍为数字格式 `1.1.4`。

## 安装与使用 Chrome 扩展

1. 从 [GitHub Releases](https://github.com/davidqiangzi/pmi-study-assistant/releases/latest) 下载扩展 ZIP 并解压。
2. 在使用 PMI 的 Chrome 配置打开 `chrome://extensions`，启用开发者模式，点击「加载未打包的扩展程序」，选择直接包含 `manifest.json` 的目录。使用源码时选择 `chrome-extension`。
3. 登录 PMI，打开点播列表或课程页。列表上选择「从当前列表选课」，课程页选择「从当前课程开始」。从其他页面可以先选择「打开点播列表」。
4. 请完整观看课程。扩展会在确认播放结束后提交 5 星评分，核对网站已保存。若 Chrome 出现原生评分提示，请点击「确定」，助手会继续核对。确认保存后再等待 3–18 秒并筛选下一门。筛选条件为 PMP/PgMP、免费和未查看，PDU 仅比较当前页。
5. 面板可查看当前课程和运行状态。点击「停止自动流程」会结束接管，保留视频和标签页。

工具栏面板使用深紫与薰衣草配色，随系统切换浅色和深色。课程标题最多显示两行，悬停可查看全文。

**更新已安装扩展**：将新文件放入同一个扩展目录，在 `chrome://extensions` 点击扩展卡片上的重新加载图标。回到 PMI 页重新启动流程。

**播放未启动**：查看扩展面板的运行状态。若同一课程页面重新加载，助手会尝试恢复播放；若已离开课程页或需要登录，请回到课程页再启动流程。

**评分待核对**：选择「打开原课程」，核实页面是否显示已保存的评分。回到原课程页可以选择「核对评分并继续」。只有在已手动核对并决定处理本次中断后，才使用「解除待核对记录」。这一操作只清除扩展的本地记录。

## 可选的 Playwright 脚本

需要 Node.js 22 或更新版本，以及本机 Google Chrome。脚本使用独立的 .profile 目录复用登录会话。首次登录时直接在 Chrome 完成 PMI 登录和可能的多因素验证。请把 .profile 当作登录凭证保管。

### 启动与配置

```sh
npm install --registry=https://registry.npmjs.org
npm start -- --inspect
```

在打开的 Chrome 中登录，通过开发者工具检查控件。在交互式终端运行时，遇到站点验证页或页面错误会保留 Chrome 窗口，便于手动验证、刷新和排查。按终端回车结束检查并保留会话。脚本内置英文与中文界面的控件名称，可先直接运行只读模式。页面结构变化或定位不明确时，可复制 site.example.json 为 site.json，按下表填写需要覆盖的选择器。

| 键 | 所需值 |
|---|---|
| signedIn | 列表页和视频页上都能唯一匹配、且只在登录后可见的账户控件选择器 |
| unviewedLabel | 「未查看」复选框的完整可访问名称，包含网站实际显示的计数（若有）。若计数随页面变化，可使用正则，例如 regex:^Not Viewed(?:\\s*\\([0-9,]+\\))?$（按 JSON 字符串转义） |
| results | 完成刷新后的课程结果容器选择器。容器应在加载过程不可匹配，并且范围仅覆盖当前筛选结果 |
| empty | 无匹配结果时可见的唯一选择器 |
| video | 正式课程的 HTML video 元素选择器，可匹配 iframe 内播放器 |
| play | 与 video 同一个页面或 iframe 内，只匹配「播放」而且不匹配「暂停」的按钮选择器 |
| fiveStars | 选择 5 分的唯一控件选择器 |
| confirm | 评分弹层中实际提交按钮的唯一选择器。若点击星级后直接显示已评分标记，可留空 |
| rated | 当前账户对此课程已完成评分的唯一可见标记，且在刷新后仍能确认 |

```sh
npm start
npm start -- --run --limit 2
npm start -- --run
```

依次运行只读筛选、最多处理两门、处理到队列清空。脚本打开课程后会点击播放，请在浏览器观看。检测到媒体暂停时，脚本会点击配置的播放按钮。若连续三次仍未恢复，脚本暂停并保留浏览器。播放器必须报告播放结束，且已播放时间段连续覆盖视频。状态不明确、控件定位失败或会话过期时，脚本会停止。

处理记录在 state/runs.jsonl。正式提交前先写入 rating_started，核对网站状态后写入 rated。上次结果不明确且课程仍出现在结果中时，脚本会先打开课程核对已评分标记。若仍无法确认，请在网站核实后再处理该课程的日志状态。日志与浏览器会话均保存在本机，适用于单一 PMI 账户。

### PDU 优先与间隔

在 site.json 配置 courseCard 为结果容器内的单门课程卡片选择器，pdu 为卡片中显示 PDU 数值的元素选择器。仅比较筛选结果当前页的课程，按 PDU 从高到低排序，同分按列表先后处理。评级成功后，如果本轮还有处理额度，脚本随机等待 3 至 18 秒，再刷新并筛选课程列表。

### 接入已打开的课程

macOS 上可使用 Chrome 144+ 的本地 Remote Debugging。当前浏览器须先开启调试，并由使用者在 Chrome 的连接弹窗中允许。将下例中的 ID 替换为指定课程 ID。

```sh
npm start -- --attach --course 1177738
npm start -- --attach --course 1177738 --run --limit 1
```

第一条只核对指定课程标签页。第二条沿用已打开的播放器和当前进度，完整观看并确认评分后关闭该课程页。省略 `--limit 1` 可继续处理后续课程。连接关闭时，脚本解除调试连接，其他 Chrome 标签页仍可使用。
